# 教学样本：办公室流程自动化设计（非运行时 Agent）

> **本目录证明什么**：如何把「每周汇总表格发邮件」拆成可教学、可复用的**流程设计包**（步骤 + 异常 + 提示词编排）。  
> **本目录不是什么**：不是可登录的 SaaS、不是常驻 Agent 运行时、不是自动发信机器人。

## 场景

**每周汇总表格发邮件**：从业务表格导出/打开数据 → 清洗 → 汇总关键指标 → 起草邮件 → 人工确认后发送 → 归档。

目标学员：需要把重复办公活标准化、以后再交给工具/助手执行的职场人（运营、行政、销售助理、数据岗等）。

## 本样本包含

| 文件 | 作用 |

| `steps.md` | 人机皆可遵循的编号步骤清单 |

## 明确边界（请先读）

1. **非 live Agent**：没有后台服务、没有定时任务、没有邮箱 API 密钥、没有自动发送。  
2. **教学 / 设计实验**：示范「如何设计流程」，不是替你每周自动跑。  
3. **人工把关**：发送前必须由人审阅；样本默认「起草 + 确认」，不鼓励无人值守发信。  
4. **无支付接口、无虚假评价、无简历模板**。  
5. **无收入承诺**：学习流程设计 ≠ 保证接单或变现。

## 建议用法（约 30–60 分钟）

1. 打开 `steps.md`，对照自己真实表格走一遍（可先用脱敏样例）。  
2. 用 `exceptions.md` 标出你业务里最常见的 3 个坑。  
3. 把表格文本粘进 `prompts.md` 的提示词，得到摘要与邮件草稿，人工改完再发。  
4. 若用于对外说明交付物，参考 `offer-one-pager.md` 的边界表述。
